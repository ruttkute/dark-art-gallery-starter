01 — Paper texture

filter: url(#paper-texture) on any element. Uses feTurbulence + feDiffuseLighting to simulate aged paper surface. Best applied to light-colored backgrounds.

Works on paper, 2024

02 — Ink dissolve (hover)

filter: url(#ink-dissolve) on hover — UI panel edges bleed and dissolve. Uses feDisplacementMap to push pixels based on a turbulence map. Applied to UI chrome: section headers, nav bars, decorative dividers — not artwork images. Hover each panel to see the effect.

The displacement scale (40) controls bleed strength. Lower = subtle edge softening. Higher (60–80) = dramatic dissolution. Animate the scale via CSS custom properties or JS for a timed effect.

03 — Watercolor edge bleed

filter: url(#watercolor-edge) on color blocks. Displaces + blurs edges to look like watercolor spreading on wet paper.
